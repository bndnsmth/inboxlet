Open source. Self-hosted on Cloudflare.

Temporary email.
For AI agents.

Give your agent an email address to receive verification codes, sign-in links, and replies. Create an inbox for each task, read or send email from your code, and delete it automatically when it expires.

Get started Get the code on GitHub ->
  • CLI, TypeScript SDK, MCP, and REST API
  • Separate access token for each inbox
  • Inboxes and messages deleted on expiry

01 / HOW IT WORKS

Create an inbox.
Receive your email.

Use a new address for each automated task. Your agent can wait for incoming email and read it without a person opening a mailbox.

  1. 01

    Create an address

    Get an email address and a private access token. Choose how long the inbox lasts.

    inboxlet create --ttl 1h
  2. 02

    Read incoming email

    Use the address in your workflow, then wait for a verification code, link, or reply.

    inboxlet read --wait 5m
  3. 03

    Delete when done

    Delete the inbox and its messages now, or let them be deleted automatically on expiry.

    inboxlet delete --yes

02 / QUICK START

Deploy once.
Create inboxes on demand.

First, deploy Inboxlet to your Cloudflare account and configure email on your domain using the setup steps below. Then use your server URL and API key in these examples.

Follow the setup guide
shell

Requires your own deployment. CLI and SDK: Node.js 22.18+. The server API key creates inboxes; each inbox has a separate access token. The MCP example uses OpenCode config.

03 / EMAIL SETUP

Connect your
email domain.

Inboxlet runs in your Cloudflare account. Configure Email Routing to receive messages and Email Sending to send messages and replies.

  1. 01

    Pick a domain

    Choose your email domain

    Choose a Cloudflare-managed domain and set MAIL_DOMAIN.

    mail.yourdomain.com
  2. 02
    Cloudflare Email Routing ->

    Receive incoming email

    Enable Email Routing, then route the inbox subdomain's catch-all address to your Inboxlet Worker.

    catch-all -> Worker: inboxlet
  3. 03
    Cloudflare Email Sending ->

    Enable sending and replies

    Enable Email Sending for your mail domain. The EMAIL binding is included in the deployment config.

    EMAIL -> send_email
